    자료 갱신

    식약처 자료를 새로 받아 사이트에 반영합니다. 보통 10~20분 걸리고, 창을 닫아도 갱신은 계속됩니다.

    처음 한 번만 GitHub 토큰을 넣어 주세요. 토큰은 이 기기의 브라우저에만 저장되고 사이트에는 올라가지 않습니다.

    토큰 만드는 법
    1. GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. Repository access: Only select repositories에서 이 저장소 하나만 고르기
    3. Permissions → Repository permissions → Actions: Read and write
    4. 만료일을 정하고 만든 뒤, github_pat_로 시작하는 토큰을 복사
