# yak · 약 성분·카피약 찾기

약 이름을 넣으면 주성분과 함량, 같은 성분의 다른 제품(카피약)을 보여 주는 사이트입니다. 의약외품과 건강기능식품도 성분·원료 기준으로 비교할 수 있습니다.

- 주소: https://mykim-app.github.io/yak/
- 자료: 식품의약품안전처 공공데이터(매주 자동 갱신)

화면 맨 위 **[의약품] [의약외품] [건강기능식품]** 버튼으로 전환합니다. 결과 화면 주소(`#seq=`, `#qd=`, `#hf=`)를 공유하면 해당 화면으로 바로 열립니다.

## 주요 기능

### 의약품

| 기능 | 내용 |
|---|---|
| 검색 | 제품 이름이나 성분 이름으로 찾기. 목록에 성분 요약 표시 |
| 오타 제안 | 결과가 없으면 비슷한 이름 제안 (예: 리조랄 → 니조랄) |
| 주성분 | 선택한 약의 성분과 함량을 캡슐 모양으로 표시 |
| 낱알 사진 | 식약처 의약품안전나라 사진 (각인·크기 포함) |
| 효능·부작용 | 식약처 자료를 짧게 줄여 표시, 원문 링크 제공 |
| 같은 성분·같은 함량 | 카피약 목록. 허가일 순 정렬, 제품별 [사진] 버튼 |
| 같은 성분·다른 함량 | 함량별로 묶어 표시 |
| 주성분이 한 가지만 다른 제품 | 복합제에서 성분 하나만 다르거나 원료 규격만 다른 제품 |
| 시중 유통 제품만 | 수출용과 공급 실적 없는 일반의약품 숨기기 (기본 켜짐) |

### 의약외품

의약품보다 작용이 약하고 약국 밖(편의점·마트)에서도 파는 제품입니다. 예: 박카스F 같은 드링크, 치약, 가글, 마스크, 생리대, 반창고, 손소독제, 염색약, 모기기피제.

| 기능 | 내용 |
|---|---|
| 검색 | 제품 이름, 성분 이름, 종류(마스크, 치약 등)로 찾기 |
| 제품 정보 | 주성분, 분류, 허가일, 효능·효과, 사용법, 사용상 주의사항 |
| 주성분 구성이 같은 제품 | 주성분이 똑같은 제품 (예: 박카스디액 ↔ 영진구론산오리지날액) |
| 주성분이 한 가지만 다른 제품 | 성분 하나만 빠지거나 바뀐 제품 |
| 같은 종류의 다른 제품 | 식약처 분류가 같은 제품. 최근 허가순 150개, 종류 전체에서 이름·회사로 찾기 가능 |

### 건강기능식품

| 기능 | 내용 |
|---|---|
| 검색 | 제품 이름이나 원료 이름(루테인, 오메가3, 유산균 등)으로 찾기 |
| 제품 정보 | 기능성 원료와 함량, 기능성, 섭취 방법, 섭취 시 주의사항 |
| 원료 구성이 같은 제품 | 기능성 원료가 똑같은 제품끼리 함량 비교 |
| 원료가 한 가지만 다른 제품 | 원료 하나만 빠지거나 바뀐 제품 |

긴 설명(주의사항 등)은 8줄까지 보이고 **더 보기**로 펼칩니다.

## 사용하는 공공데이터

모두 공공데이터포털(data.go.kr)에서 같은 인증키로 활용신청합니다. 개발계정은 자동 승인이고 하루 10,000회까지 호출할 수 있습니다.

| API | 쓰는 곳 | 필수 여부 |
|---|---|---|
| 식품의약품안전처_의약품 제품 허가정보 (`DrugPrdtPrmsnInfoService08`) | 의약품 목록, 주성분, 허가사항(효능·부작용), 낱알 사진 | 필수 |
| 식품의약품안전처_의약품개요정보(e약은요) (`DrbEasyDrugInfoService`) | 일반의약품 공급 실적, 쉬운 말 효능·부작용 | 선택 |
| 식품의약품안전처_의약외품 제품 허가정보 (`QdrgPrdtPrmsnInfoService03`) | 의약외품 목록, 주성분, 분류, 효능·사용법·주의사항 | 선택 |
| 식품의약품안전처_건강기능식품정보 (`HtfsInfoService03`) | 건강기능식품 제품·원료·기능성 | 선택 |

선택 API를 신청하지 않으면 해당 기능만 빠지고 나머지는 정상으로 만들어집니다.

## 처음 설정

1. **인증키 받기**: 공공데이터포털에서 위 API를 활용신청하고, 마이페이지에서 일반 인증키를 복사합니다. 승인 직후에는 1~2시간 동안 "등록되지 않은 서비스키" 오류가 날 수 있습니다.
2. **인증키 등록**: 저장소 Settings → Secrets and variables → Actions → New repository secret
   - 이름: `DATA_GO_KR_KEY`
   - 값: 인증키 (Encoding·Decoding 어느 쪽이든 가능)
3. **작업 권한**: Settings → Actions → General → Workflow permissions를 **Read and write permissions**로 지정합니다.
4. **자료 받기**: Actions 탭 → "의약품 자료 갱신" → Run workflow. 끝나면 `data` 폴더가 자동으로 올라옵니다.
5. **게시**: Settings → Pages → Source는 "Deploy from a branch", Branch는 `main` / `(root)`로 지정합니다.

## 자동 갱신

- 매주 월요일 새벽 3시(한국시간)에 자동으로 실행됩니다.
- 한 번 실행에 **약 50~65분**이 걸립니다. 의약품 허가사항 문서가 커서 대부분의 시간이 여기에 쓰입니다. 제한 시간은 150분입니다.
- 호출량은 한 번에 약 2,900회로 하루 한도 안에 들어갑니다.
- 응답이 늦은 쪽은 20건씩 나눠 다시 받고, 그래도 안 되는 부분은 건너뛴 뒤 다음 갱신 때 다시 받습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (의약품·의약외품·건강기능식품) |
| `scripts/collect.mjs` | 공공데이터 수집과 검색 자료 생성 |
| `.github/workflows/update-data.yml` | 매주 자동 갱신 |
| `data/drugs.json` | 의약품 검색 자료 (제품, 성분, 사진 주소) |
| `data/info/*.json` | 의약품 효능·부작용 요약 (성분 조합별, 128개로 나눔) |
| `data/qd.json` | 의약외품 검색 자료 (제품, 성분, 분류) |
| `data/qd-info/*.json` | 의약외품 효능·사용법·주의사항 (64개로 나눔) |
| `data/hf.json` | 건강기능식품 검색 자료 |
| `data/hf-info/*.json` | 건강기능식품 기능성·섭취 방법·주의사항 (128개로 나눔) |
| `data/meta.json` | 갱신일과 건수 |

`data` 폴더는 자동 갱신 때마다 새로 만들어지므로 직접 고치지 않습니다.

> **직접 올릴 때 주의**: GitHub 웹 화면의 파일 올리기는 한 번에 **100개까지만** 받습니다. `info`, `hf-info`처럼 파일이 128개인 폴더는 두 번에 나눠 올려야 뒤쪽 파일이 빠지지 않습니다. 가능하면 Actions의 Run workflow로 자료를 만드는 편이 안전합니다.

## 묶는 기준

**의약품**
- 같은 성분·같은 함량: 주성분 코드와 함량·단위가 모두 같은 제품
- 같은 성분·다른 함량: 주성분 구성은 같고 함량만 다른 제품
- 제형(정제·캡슐·주사 등)은 기준에 들어가지 않으므로 제품명으로 확인합니다.
- 같은 성분이라도 염이나 원료 표기가 다르면(예: 아토르바스타틴칼슘삼수화물 ↔ 아토르바스타틴칼슘) 다른 성분으로 봅니다.

**의약품 시중 유통 판단**
- 이름에 "수출용"이 붙은 제품은 국내 판매가 없는 것으로 봅니다.
- 일반의약품은 e약은요(공급 실적 있는 제품 목록)에 있어야 유통 제품으로 봅니다.
- 전문의약품은 공급 실적 자료가 없어 수출용만 뺍니다. 건강보험 코드는 비급여 약(비아그라, 위고비 등)에 없어서 기준으로 쓰지 않습니다.

**의약외품**
- 주성분 구성(성분 이름)이 같은 제품끼리 묶습니다. 자료에 함량이 없어서 함량은 비교하지 않습니다.
- 폐업·취소·취하된 제품과 수출용 제품은 뺍니다.
- 주성분이 없는 제품(마스크, 생리대 등)은 식약처 분류로 비교합니다.

**건강기능식품**
- 식약처 기준규격 문구 중 "표시량"이 적힌 줄을 기능성 원료로 봅니다.
- 함량은 "20mg/500mg"처럼 섭취 단위당 값이며, 제품마다 기준 단위가 다를 수 있습니다.
- 업체용 원료(섭취 방법이 "원료로 사용"인 것)는 뺍니다.

## 한계

- 약국별 재고나 공급 내역은 공개 자료가 없어 확인할 수 없습니다.
- 효능·부작용·주의사항은 원문을 자동으로 정리한 것이라 일부 표현이 매끄럽지 않을 수 있습니다. 정확한 내용은 원문 링크에서 확인합니다.
- 낱알 사진은 의약품의 약 61%에만 있습니다(액제·연고·주사제는 대부분 없음). 의약외품과 건강기능식품은 사진이 없습니다.
- 의약외품은 약 66%(마스크·생리대·밴드 등)에 주성분 정보가 없고, 함량 자료가 없습니다.
- 건강기능식품은 약 8%의 제품에서 원료를 읽지 못하며, 가격·판매 여부 자료가 없습니다.

## 알림

이 사이트는 공공데이터를 찾아보기 쉽게 정리한 것이며 의학적 조언이 아닙니다. 성분과 함량이 같아도 제형, 첨가제, 허가받은 효능이 다를 수 있으므로, 약을 바꾸거나 새로 드실 때는 의사·약사와 상담하세요.
